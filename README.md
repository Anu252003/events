Project : Event Page

In the project, we will build an Event Page that will cover a wide range of fundamental HTML components. Throughout this project, you will learn how to use the following HTML elements:

1. Heading Tags: <h1>, <h2>, <h3>, <h4>, <h5>, <h6>
2. Paragraph Tags: <p>
3. Anchor Tags: <a>
4. Body Tag: <body>
5. HTML Boilerplate: <html>
6. Image Tag: <img>

By the end of this project, you will have a clear understanding of how to structure basic HTML elements and create an appealing Event Page.
